San Diego Public Restroom Access Audit ACTIVE DEVELOPMENT

Open-source web mapping • field auditing • moderated submissions • live geospatial data

  • Built a public-facing Leaflet map for exploring public restroom locations across San Diego County
  • Restroom markers communicate current recorded status: open, closed, or unknown
  • Developed a button-triggered field audit interface for both new restroom submissions and updates to existing locations
  • New restroom coordinates can be collected through map interaction or device geolocation
  • Existing restrooms use persistent identifiers so repeat audits update the correct location rather than creating duplicate records
  • User submissions enter a review queue and do not immediately alter the public dataset
  • Approved records are promoted into the public-facing restroom dataset through Google Apps Script
